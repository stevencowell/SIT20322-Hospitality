Task 2 · Activity 11

Match the product to the request

Use a supplied neutral menu to recommend accurately without promising unavailable or unverified features.

25 minutesPairsAutosaves locallyPrint-ready
Return to linked lesson

Supplied context

The scenario

Fictional café menu: A—fruit cup, chilled, takeaway available; B—vegetable toastie, served hot, contains wheat and dairy; C—garden salad, dressing supplied separately, dine-in or takeaway; D—soup of the day, hot, ingredients must be checked with the kitchen. Prices and local recipes are deliberately omitted.

Materials

Interactive practice

Complete the job

Needs a cold item that can be taken away

Asks whether soup contains a particular allergen

Wants a hot item and has confirmed wheat and dairy are suitable

Wants dressing controlled separately

Method

Steps

  1. Read the complete menu stimulus.
  2. Match four requests.
  3. Write a recommendation using feature → benefit → confirmation.

Success criteria

  • Recommendation uses supplied facts
  • Allergen information is checked
  • No price or availability is invented
  • Customer confirms the match

Support

Use: 'This option has… which may suit… Would that meet your need?'

Extension

Identify one question that would change the recommendation for each menu item.

Teacher delivery note

Set-up

The stimulus and core materials are supplied. Substitute a local authorised source only when it materially improves relevance and is safe to share.

Observe

Listen for use of evidence, accurate language, authority boundaries and the learner's explanation—not just the final selection.

Debrief

Ask one group to defend a decision, one group to identify a likely error and one group to state the next source or person to confirm with.
