Source credibility matrix

Compare authority, currency, relevance and evidence before using hospitality information at work.

Supplied context

The scenario

Source A is a current training.gov.au unit page that identifies its code, release, application and evidence requirements. Source B is an undated social post saying 'every venue does it this way' with no author, workplace context or supporting link.

Materials

  • This page and the supplied scenario
  • Your saved learning record

Interactive practice

Complete the job

Method

Steps

  1. Compare both supplied source descriptions.
  2. Rate authority, currency, relevance and evidence.
  3. Write the workplace decision each source can and cannot support.
  4. Record a second independent source you would seek.

Success criteria

  • Authority and popularity are separated
  • Currency is checked
  • Use is matched to purpose
  • A verification step is named

Support

Use A-C-R-E: authority, currency, relevance, evidence.

Extension

Explain why an official source can still be irrelevant to a specific local procedure.

Teacher delivery note

Set-up

The stimulus and core materials are supplied. Substitute a local authorised source only when it materially improves relevance and is safe to share.

Observe

Listen for use of evidence, accurate language, authority boundaries and the learner's explanation—not just the final selection.

Debrief

Ask one group to defend a decision, one group to identify a likely error and one group to state the next source or person to confirm with.
