Task 3 · Lesson 4

Sources, compliance and quality

Choose and test hospitality information sources, route compliance questions to the responsible authority and connect quality information to an authorised improvement.

Learning intention

What success looks like

  • I can select source types from regulators, industry bodies, experienced people, suppliers, training and workplace systems for a defined purpose.
  • I can test authority, currency, jurisdiction, relevance and traceability before using a claim.
  • I can distinguish legal requirements, ethical practice, quality assurance and local procedure.
  • I can turn a verified finding into a practical improvement while preserving an advice and authority boundary.

Worked example

Hospitality information comes from different kinds of authority

Useful sources can include government regulators, developers of codes or ethics, industry associations, accreditation operators, unions, training, journals, seminars, suppliers, colleagues, experienced industry personnel and personal observation. Each source type has a different purpose. A regulator may explain a law in plain English; a supplier may explain a product update; a workplace procedure controls the local method.

A worker notices that two team members describe a food-business requirement differently. The observation identifies a need to check; the current NSW regulator source clarifies the public guidance; the authorised workplace process determines how the local team applies it.

Question the room

A worker needs current plain-English information about a NSW food-business requirement. Where should the search begin?

  1. A current NSW regulator source responsible for food-business guidance.
  2. An undated personal blog because it uses simple language.
  3. Another student's submission from a previous class.

Apply

Source credibility matrix

Source A is a current training.gov.au unit page that identifies its code, release, application and evidence requirements. Source B is an undated social post saying 'every venue does it this way' with no author, workplace context or supporting link.

  1. Compare both supplied source descriptions.
  2. Rate authority, currency, relevance and evidence.
  3. Write the workplace decision each source can and cannot support.
  4. Record a second independent source you would seek.
