Turn a broad hospitality topic into a focused workplace question, distinguish current evidence from opinion and show how information can improve day-to-day work.

Learning intention

What success looks like

  • I can explain why hospitality workers need current industry information rather than a collection of general facts.
  • I can frame a focused question for a named role, context and decision.
  • I can distinguish a sourced fact from my interpretation and a proposed workplace action.
  • I can plan a source search without inventing a statistic, trend or local requirement.

Worked example

Industry knowledge belongs in day-to-day work

Hospitality workers use industry information when they explain a service, respond to a change, check a requirement, choose a reliable source or suggest an improvement. Useful knowledge is connected to an operational duty. It helps a worker make a clearer decision, communicate accurately or recognise when an issue must be checked with someone who has authority.

A café team hears that a digital ordering feature has changed. The useful question is not simply whether the feature is popular. The team needs to know what has changed in the order workflow, which source confirms it, what staff must learn and how service continues if the feature is unavailable.

Question the room

Which question is most useful for a hospitality worker preparing for a new ordering process?

  1. What is everything that has ever changed in hospitality technology?
  2. How does the authorised ordering process change my accuracy checks and who confirms the fallback when the system is unavailable?
  3. Is the new screen better than the old one?

Apply

Source credibility matrix

Source A is a current training.gov.au unit page that identifies its code, release, application and evidence requirements. Source B is an undated social post saying 'every venue does it this way' with no author, workplace context or supporting link.

  1. Compare both supplied source descriptions.
  2. Rate authority, currency, relevance and evidence.
  3. Write the workplace decision each source can and cannot support.
  4. Record a second independent source you would seek.
